# RWANG Repository Unification Wave 4: Package Boundaries

## Objective

Import the smallest coherent internal package-boundary slice from the canonical
monorepo provenance without rewiring the live runtime. This wave establishes
reproducible workspace links, source packages, and package-boundary tests.

## Scope

Allowed files are the root `package.json`, `pnpm-lock.yaml`,
`pnpm-workspace.yaml`, `turbo.json`, `packages/contracts/**`,
`packages/core/**`, `tests/workspace-contracts.test.mjs`, and this evidence
document.

Forbidden files include `engine.mjs`, `planner.mjs`, `providers.mjs`,
`session-leases.mjs`, package READMEs, provider/account/store configuration,
benchmark or Ollama files, GoVibe or target repositories, generated state, and
Wave 1-3 evidence.

## Provenance And Dependency

- Base: Wave 3 final branch tip `aabc9c8`.
- Source: `3ec4a8a95e0cdfbc6ea6fcb8f2733db53fbf6117`.
- Root metadata preserves Wave 3 scripts and the Tauri dependency while adding
  pnpm workspace identity, internal links, and Turbo commands.
- `pnpm-lock.yaml` is generated by pnpm 11.9.0 from the reconciled manifest.

## Architecture Mapping

| Source | Wave 4 target | Boundary rule |
|---|---|---|
| Contracts source | `@rwang/contracts` | Owns canonical task and adapter-shape contracts. |
| Core routing source | `@rwang/core` | Owns reusable model-routing helpers only. |
| Workspace manifest | `pnpm-workspace.yaml` | Discovers `packages/*` only. |
| Task graph | `turbo.json` | Orchestrates package tasks without implying missing apps. |
| Workspace test | `tests/workspace-contracts.test.mjs` | Validates installed bare package exports. |

The live runtime continues to use its existing imports. `engine.mjs`,
`planner.mjs`, and `providers.mjs` are intentionally not rewired.

## Migration Dependencies

1. Wave 3 must land first.
2. Consumers install with pnpm 11.9.0 and the committed lockfile.
3. Runtime rebinding may occur only after behavior-parity tests are approved.
4. Session affinity remains a separate migration.

## Acceptance Criteria

- Root metadata preserves Wave 3 runtime scripts and existing dependencies.
- `@rwang/contracts` and `@rwang/core` resolve through declared exports.
- Turbo discovers and tests both packages.
- Existing engine and planner imports remain untouched.
- No session-affinity or unrelated feature is imported.
- No external consumer or target repository is embedded.
