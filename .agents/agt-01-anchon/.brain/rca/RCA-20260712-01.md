# RCA-20260712-01 — H-axis overload

**Date:** 2026-07-12 · **Subject:** GenesisBlock `H0–H6` "AI Context Scaling" axis
**Verdict:** semantic-collision defect in the document, caused by an authoring-time agent conflation.

---

## 1. Root (what the thing originally was)
A **document-authoring** system. A phased pipeline — requirement → BRD → PRD → SRS → … → code — where
each phase is a **document altitude**, and **C (C0–C3)** gates how many phases a given task needs.
Everything is normalized into atoms and JOIN-compiled back into views on demand. Original purpose:
**kill document drift.**

## 2. Original problem (what the root set out to solve)
Documents drift / duplicate / go out of sync. Solved correctly by **graph-SSOT + views-as-queries +
single-point-of-mutation** — the part all four independent reviews praised. No defect here.

## 3. First fix (the misstep)
The document-altitude ladder was **reinterpreted a second time as "AI Context Scaling H0–H6"** — one
symbol `H` made to serve **two purposes at once** (authoring altitude *and* runtime agent-context
scope). The unification happened at authoring time, **AI-assisted and without a consolidation pass**
(marks: unconsolidated transcript posing as a blueprint, flattery, ends with a question back to the user).

## 4. Problem the first fix created (why a second fix is needed)
With `H` carrying two worlds, it now **conflates ≥4 things** (altitude · radius · task-type ·
authority/budget). Symptoms:
- Internal contradiction: schema enum `H0–4` vs table `H0–6`.
- Un-routable / un-reasonable: "read more" ≠ "allowed to change more."
- **Mock-poisoning landmine**: permissive AI-mock (`DRAFT_MOCK`) flows into the shared SSOT unfiltered.
- Cross-system confusion: Rwang collapsed `H0–6 → H0–4` (correct for *capability*-H), which then gets
  mis-compared against GenesisBlock's *altitude*-H — comparing different axes wearing the same letter.

The **over-unification is the second problem** — the one under repair now.

## 5. What we are fixing now — whose mismatch
- It is a **mismatch in the document** (the map): one letter `H` = two legitimate but different concepts
  (authoring-altitude vs runtime-context). A **semantic collision**, not a factual error.
- **Root mechanism = authoring-time conflation** (model + human co-authored an over-clever unification
  and never consolidated it). NOT a live runtime hallucination.
- **Second-order finding (honesty):** the *diagnosing* agents are susceptible to the same conflation.
  This session the coordinator (Opus) mislabelled `D` as "resolution gradient" (it is Compaction Depth,
  SPEC §6) and proposed a `C-derived default` that breaks for altitude-H; fable-critic caught both.
  → the anti-anchoring + 4-model check exists precisely because the reviewers are not immune either.

## Fix (independently verified 4/4 — fable-5, gpt-5.5, gpt-5.6-sol, Rwang)
**Un-fuse into two worlds**, and keep `H0–6` only as a **preset** over the real axes:
- **Authoring:** `C` (complexity → how many doc phases) · `D` (compaction depth / altitude).
- **Runtime:** `Radius` (traverse) · `Budget` (per-agent token ceiling → handoff) · `Resolution`
  (content thins with distance, structure never) · `Write-authority` (mock quarantine).
- **Bonus:** `isolation_level: strict|permissive` should **derive from C** — high-C ⇒ strict ⇒ no
  AI-mock, gather real requirements ("never assume"); low-C ⇒ permissive. This makes the mock
  quarantine automatic for high-stakes work using the project's own C axis.
